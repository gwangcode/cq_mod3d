# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-05-XX

### Added
- Initial release.
- Operator overloading for `cq.Workplane` (`+`, `-`, `*`, `@`, `%`, `^`).
- Procedural noise generation (`apply_noise`, `apply_noise_wire`).
- Pure B-rep slice-and-loft twist algorithm (`brep_twist_z`).
- Over 30 built-in 2D/3D primitives and mathematical curves.

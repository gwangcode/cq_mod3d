# Contributing to cq_mod3d

We love your input! We want to make contributing to this project as easy and transparent as possible.

# Development Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/gwangcode/cq_mod3d.git
   cd cq_mod3d
   ```
   
2. Install in editable mode with test dependencies:

   ```bash
   pip install -e .
   pip install pytest
   ```
   
3. Run the test suite:

   ```bash
   pytest tests/
   ```
   
# Pull Request Process
  1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.

  2. Update the README.md with details of changes to the interface.

  3. You may merge the Pull Request in once you have the sign-off of the maintainer.
